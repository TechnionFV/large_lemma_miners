- If `y < 0`, then `flag` is set to 1.
- If `flag < 1` still holds after the above step, then `x` is incremented by 1.
- `y` is then updated depending on the value of `x`:
  - If `x < 50`: increment `y`.
  - Else: decrement `y`.

The system evolves through two phases:
1. **Ramp-up phase** (`x < 50`):  
   - `x` and `y` both increment together.
   - In this phase, `x == y` always holds.
2. **Ramp-down phase** (`x >= 50`):  
   - `x` continues to increment, `y` begins to decrement.
   - Once `y == -1`, `flag` is set to 1, y is decremented by 1 and the system halts.

The property states that either the system is still active (flag < 1, there are still updates), or it has halted in a specific final state: x == 99 and y == -2.
I.e., it expresses a safety condition on the halting state.
