## Module Behavior and Property Meaning:

This module defines two 32-bit registers x and y, and a constant 32-bit wire n = 100.

Initial state:
- x = n = 100
- y = 0

On every rising clock edge:
- If x > 0:
  - x is decremented by 1
  - y is incremented by 1

This continues until:
- x = 0
- y = 100

Thus, x transfers its value into y, one unit per clock cycle.

The property states that on every clock cycle:
- Either x > 0 (the system is still active, i.e., there are still updates to the values of the registers), or
- y == n 

It is a safety property that asserts that if x has finished decrementing (x == 0), then y must equal 100.

### Proposed Lemma: 
We propose a stronger, 1-inductive invariant which implies the property. It sates that the total sum of x and y remains constant at n throughout execution, and that x is nonnegative.
- It holds in the initial state (x = 100, y = 0), and
- It is preserved on every transition (x decreases by 1 as long as it is strictly positive, y increases by 1, and hence their sum remains constant).


This lemma implies the property, since if `x > 0` does not hold, by the lemma, x must equal zero, and since `x + y == n`, y must then equal n.
